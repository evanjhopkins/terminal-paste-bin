Less clipboard archaeology.

TPB keeps the useful fragments in predictable, keyboard-addressable slots. No daemon. No account. No context switch.

01

Ten slots, zero hunting.

Slots map directly to 1 through 9, then 0. Your hands already know where to go.

02

Named bins.

Keep myapp, production, and scratch

03

System clipboard in, out.

Write your current clipboard to a slot, or read a slot directly back to the system clipboard.

04

Local by default.

Small local JSON files. Atomic writes. Nothing leaves your machine.

The flow

Keep it close.
Keep moving.

Built for the small bits of text that interrupt real work when they disappear.

01

Open a bin

Run tpb for a register scoped to the current directory, or tpb myapp for a project-specific one.

02

Choose a slot

Press a number or use the arrow keys. No mouse, no Enter, no ceremony.

03

Read or write

w saves the system clipboard. r copies the selected slot back when you need it.
